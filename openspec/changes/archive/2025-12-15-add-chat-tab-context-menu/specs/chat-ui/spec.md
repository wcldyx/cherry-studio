## ADDED Requirements
### Requirement: 聊天标签右键菜单关闭
聊天标签栏 MUST 提供浏览器式右键上下文菜单，支持在指定标签上直接关闭自身或关闭其他标签，且不影响已有左键、滚轮、拖拽排序或中键关闭的交互。

#### Scenario: 右键关闭当前标签
- **WHEN** 用户在可关闭的聊天标签上点击右键并选择“关闭标签”
- **THEN** 系统 MUST 关闭该标签及其对应的会话，收起菜单，保持相邻或最近使用的标签被激活，且其他标签的排序与状态不受影响。

#### Scenario: 右键关闭其他标签
- **WHEN** 用户在某个聊天标签上点击右键并选择“关闭其他标签”
- **THEN** 系统 MUST 保留该标签为激活态，同时关闭其他所有可关闭的标签（保留新建按钮等不可关闭元素），并同步侧栏主题列表与标签栏的激活状态。
