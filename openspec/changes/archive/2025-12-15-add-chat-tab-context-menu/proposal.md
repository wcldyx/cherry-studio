# Change: 右键菜单关闭聊天标签

## Why
- 聊天标签栏缺少浏览器式右键操作，无法直接关闭当前或关闭其它标签，降低多标签管理效率。
- 用户希望对齐 Chrome 的习惯，用右键即可完成常见关闭操作，而无需额外滚动或点击关闭按钮。

## What Changes
- 在聊天标签上提供右键上下文菜单，包含“关闭标签”“关闭其他标签”操作，行为与 Chrome 标签栏一致。
- 关闭操作需同步标签/会话状态与侧栏主题列表，避免出现残留激活态或视图不同步。
- 交互与现有左键选中、中键关闭、拖拽排序、滚动等能力兼容，不增加额外干扰。

## Impact
- Affected specs: chat-ui
- Affected code: renderer 聊天标签栏组件与标签关闭逻辑（状态管理、UI 交互）
